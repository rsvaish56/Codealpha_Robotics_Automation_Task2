# CodeAlpha Robotics Automation - Task 2

## Project Overview
This repository contains the complete submission for Task 2 of the CodeAlpha Robotics Automation Internship. The project focuses on designing, setting up, and automating a robotic simulation environment (Pick and Place operations) using RoboDK and evaluating its performance.

## Repository Contents
* **codealpha_task2.rdk**: The primary RoboDK simulation project file containing the robotic arm configurations, reference frames, and targets.
* **Simulation_Report.pdf**: A comprehensive technical report detailing the simulation design, objectives, methodologies, and final analysis.
* **prog1.html**: Custom web-based interface or script related to the project automation/monitoring.
* **stimulation.mp4**: A complete video recording demonstrating the successful execution of the robotic simulation.
* **Home position.png / Pick position.png / Place position.png**: High-resolution screenshots showing key states of the robotic arm during execution.

## Simulation Details
* **Operation**: Automated Pick and Place sequence.
* **Key Positions Tracked**: 
  1. Home Position (Starting state)
  2. Pick Position (Object gripping)
  3. Place Position (Target release)

## How to Review This Project
1. **Report**: You can download `Simulation_Report.pdf` directly to view the full project documentation.
2. **Simulation**: To run the interactive simulation, open the `codealpha_task2.rdk` file locally using the RoboDK application.
3. **Video**: Download and watch `stimulation.mp4` for a quick visual demonstration of the automation process.
